# Description of example StoX projects for StoX 4.2.0:

# Note that Bootstrap-processes are run with NumberOfBootstrap = 50 on NumberOfCores = 10. Usually a lot more runs are needed to gain sufficient precision in the CV estimate. A typical number is NumberOfBootstrap = 1000.

## Example_StoX_v4.2.0_acoustic-trawl_sandeel: 
- This project is a minimal acoustic-trawl project producing bootstrap estimates of sandeel in the North Sea, containing data in two strata. 50 bootstrap replicates are used on 10 cores. 

## Example_StoX_v4.2.0_convert_length: 
- This project is a swept-area project for shrimp reading NMDBiotic-xml file, where length is multiplied by (the arbitrary value) 1.2 and lengthmeasurement translated from "C" to "E" in order for StoxBiotic to accept the lengths as IndividualTotalLength.

## Example_StoX_v4.2.0_export_IESSNS2015_Eros_accepted_at_ICES: 
- This project exports a biotic file in the ICESBiotic CSV format which is accepted on submission on https://acoustic.ices.dk/.

## Example_StoX_v4.2.0_export_NMDEchosounder_to_ICESAcoustic:
- This project reads an ICESAcoustic-xml file generated by LSSS and exports ICESAcoustic-csv file after some translations and filtering.

## Example_StoX_v4.2.0_SpeciesCategoryCatch: 
- This project reads a minimal NMDBiotic (version 3.1) xml-file and generates a table with catch weight or number per station in the rows and species in the columns (added info about the hauls in the first columns).

## Example_StoX_v4.2.0_SplitNASC:
- This project is an acoustic-trawl project where the acoustic data in a mix acoustic category are split using the function SplitMeanNASC().

## Example_StoX_v4.2.0_swept-area_cod: 
- This project is a minimal swept-area project producing bootstrap estimates of cod in the Barents Sea, containing data in two strata. 50 bootstrap replicates are used.

## Example_StoX_v4.2.0_swept-area_cod_total_catch: 
- This project is a copy of the project Example_StoX_v4.2.0_swept-area_cod, but producing total catch estimates instead of length based estimates.

## Example_StoX_v4.2.0_swept-area_translate_maturity: 
- This project is a swept-area project reading ICESBiotic-xml file, where maturity is interpreted and reported on.

## Example_StoX_v4.2.0_transect_design: 
- This project is a small project where the TransectDesign and StationsAlongTransectdesign functions and corresponding report functions are demonstrated.
